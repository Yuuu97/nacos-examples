## nacos-config-example 完整示例代码实现

根据《第二篇：Nacos配置中心——通信推送与动态刷新源码分析》文章，完整创建了覆盖文章三大核心机制的代码示例。

### 创建的文件

| 文件 | 说明 |
|---|---|
| `src/main/resources/bootstrap.yml` | Bootstrap 引导上下文配置（Nacos 连接参数 + spring.config.import） |
| `src/main/resources/application.yml` | 应用配置（本地兜底 + 业务配置） |
| `config/DynamicConfigProperties.java` | @ConfigurationProperties + @RefreshScope 配置绑定 |
| `controller/ConfigDemoController.java` | @RefreshScope REST 控制器，演示动态刷新效果 |
| `controller/NacosApiController.java` | ConfigService API 直接调用演示（getConfig/addListener/publishConfig/publishConfigCas） |
| `listener/ConfigChangeMonitor.java` | RefreshScopeRefreshedEvent 监听 + @Scheduled 定时配置打印 |
| `NacosConfigExampleApplication.java` | 主启动类（增强注释 + @EnableScheduling） |
| `README.md` | 完整文档（包含文章源码对照表和核心链路梳理） |

### 关键技术决策

- Nacos API 接口（ConfigService/Listener/NacosException）在 2.4.3 中从 nacos-client 分离到 nacos-api 模块，需在 pom.xml 中显式添加 nacos-api:2.4.3 依赖
- Spring Cloud 2023.0.4 中 RefreshEvent 包路径变更，使用 RefreshScopeRefreshedEvent 替代
- 通过 NacosConfigManager.getConfigService() 获取 ConfigService 实例（而非直接 @Autowired ConfigService）
- commons-codec 的 DigestUtils 可用 Spring 内置的 DigestUtils 替代
